# portfolio-folio — 3D 책장 포트폴리오

검은 화면에 큰 이름이 있고, 그 아래 프로젝트 책 줄이 사선으로 놓인 한 화면짜리 포트폴리오입니다.
책 한 권이 프로젝트 하나이고, 마우스 근처의 책이 스프링 물결로 올라오며, 책을 누르면 오른쪽에서 상세 패널이 열립니다.
오른쪽 아래 "11권 펼쳐 보기"(또는 메뉴 Projects)를 누르면 프로젝트 책이 한 줄에 4권(휴대폰 2권)씩 정렬되고 아래로 스크롤됩니다. 다시 누르거나 Esc 를 누르면 책장으로 돌아갑니다.
책장 화면은 아래로 스크롤하면 책 밑동까지 보이고, 맨 아래에 연락처(이름 · 전화 · 이메일 · GitHub · 사이트)가 있습니다.
(motionsites.ai 의 "Folio" 프롬프트 구조를 바탕으로, 표지 이미지는 쓰지 않고 캔버스로 직접 그립니다.)

빌드 없는 정적 사이트입니다. Three.js r160 은 jsDelivr 의 import map 으로 불러옵니다.

```
python3 -m http.server 4321   # 이 폴더에서 실행 → http://localhost:4321
```

## 파일

| 파일 | 하는 일 |
|---|---|
| `index.html` | 메뉴 · 큰 이름 · 키워드 · 캔버스 · 상세 패널 틀 |
| `styles.css` | 레이아웃, 패널, 휴대폰(≤760px), 움직임 줄이기 설정 |
| `js/projects.js` | **프로젝트 내용** — 글을 고칠 때는 여기만 고치면 됩니다 |
| `js/covers.js` | 표지 · 종이 단면을 캔버스로 그리기 (`MOTIFS` = 표지 도형) |
| `js/scene.js` | 렌더러 · 조명 · 카메라 · 책 줄 배치 (`FILLER_SLOTS` = 장식 책 자리) |
| `js/motion.js` | 책장: 마우스가 올라간 책(보이는 띠 기준) 한 권이 올라오고 옆 책은 조금만 · 책마다 스프링 (K 42, C 12, 프레임당 4번) · 펼치기: 가리킨 책이 앞으로, 장식 책은 가라앉음 |
| `js/page.js` | 책장 화면 스크롤 — 내리면 카메라도 같이 내려가 책 밑동과 맨 아래 연락처가 보임 |
| `js/layout.js` | 펼치기 격자 자리 계산, 책마다 책장 ↔ 격자 진행값 스프링(감쇠비 1, 차례로 출발) |
| `js/view.js` | 책장 / 펼치기 전환 — 버튼 글자, `grid-mode` 클래스, 스크롤 영역 높이 |
| `js/panel.js` | 상세 · 소개 패널, 이전/다음 프로젝트 |
| `js/intro.js` | 첫 등장 애니메이션 |
| `js/main.js` | 시작점 — 위 모듈을 묶고 클릭 · 매 프레임 갱신 |

## 프로젝트 추가 · 순서 바꾸기
`js/projects.js` 의 `PROJECTS` 배열 순서가 책 순서(앞 → 뒤)입니다.
11개보다 늘리면 `scene.js` 의 `FILLER_SLOTS` 를 줄여서 프로젝트 책이 화면 안(앞에서 2~15번째)에 오게 합니다.
