시작 파일에는 가상 아이템 20종이 값만 들어 있어요. 오늘은 이 데이터를 **기획 데이터 표답게 정리**하면서 엑셀 화면과 단축키에 손을 익혀요. 직접 20행을 입력하고 싶으면 빈 통합 문서로 시작해도 돼요. 이 경우 시작 파일은 입력할 값을 볼 때만 참고해요.

- 엑셀을 열고 **파일 > 계정**에서 "Microsoft 365" 제품인지 확인해요
- 오늘 만든 파일은 한 폴더(예: `문서\maple-study\excel`)에 모아 두면 다음 날 이어서 쓰기 편해요

> **버전 차이 주의** Mac용 엑셀은 <kbd>Ctrl</kbd> 대신 <kbd>Cmd</kbd>를 쓰는 단축키가 많고, 리본 단축키(<kbd>Alt</kbd> 순서 누르기)가 없어요. 웹용 엑셀은 일부 대화 상자 모양이 달라요. 이 자료는 Windows 데스크톱 기준이에요.

## 개념 설명

### 엑셀 화면 구성

| 이름 | 위치 | 하는 일 |
|---|---|---|
| 리본 | 맨 위 탭 (홈, 삽입, 수식, 데이터…) | 기능 버튼이 탭별로 모여 있어요 |
| 이름 상자 | 수식 입력줄 왼쪽 칸 | 지금 선택한 셀 주소(예: `F2`)가 보이고, 주소를 입력해 바로 이동할 수 있어요 |
| 수식 입력줄 | 리본 아래 긴 칸 | 셀에 **실제로 들어 있는 값이나 수식**이 보여요 |
| 시트 탭 | 화면 맨 아래 | 한 파일(통합 문서) 안의 여러 시트를 오가요 |
| 상태 표시줄 | 화면 맨 아래 오른쪽 | 선택한 셀들의 평균·개수·합계를 바로 보여줘요 |

계층은 **통합 문서(파일) > 시트 > 행·열 > 셀**이에요. 기획 데이터는 보통 "테이블 하나 = 시트 하나"로 나눠요.

### 값과 표시 형식은 다르다

셀에 `1500`을 넣고 표시 형식을 `#,##0"메소"`로 바꾸면 화면에는 `1,500메소`가 보여요. 하지만 수식 입력줄에는 여전히 `1500`이 보이고, 계산에도 숫자 1500이 쓰여요. **서식은 보이는 모습만 바꿔요.** 그래서 단위를 셀에 글자로 직접 입력하면(`1500메소`) 숫자가 아니라 글자가 되어 합계를 낼 수 없어요.

### 기획 데이터 표의 3원칙

1. **머리글은 1행에 한 줄만.** 열 이름은 영어 키(`item_id`)나 짧은 한글로 써요.
2. **한 셀에 한 값.** "소비/레어"처럼 두 정보를 한 셀에 넣지 않아요.
3. **병합 셀 금지.** 병합 셀이 있으면 정렬·필터·참조가 깨져요.

### 게임 기획에서 어디에 쓰나

아이템·몬스터·보상 같은 **데이터 테이블**은 개발자가 그대로 읽어 게임에 넣어요. 그래서 기획자가 만든 표가 곧 게임 데이터예요. ID 규칙이 일정하고, 빈칸·병합 없이 깔끔해야 오류가 안 나요. 오늘 만드는 아이템 시트가 앞으로 2주 동안 쓸 "가을 이벤트 워크북"의 첫 테이블이에요.

## 따라 하기

1. **시작 파일 열기와 저장**
   시작 파일을 열고 바로 <kbd>F12</kbd>(다른 이름으로 저장)를 눌러 `excel-01_item-master.xlsx`로 저장해요.
   결과: 제목 표시줄에 새 파일 이름이 보여요.

2. **시트 이름 확인하기**
   맨 아래 시트 탭 `아이템`을 더블클릭하면 이름을 고칠 수 있어요. 이름은 그대로 두고 <kbd>Esc</kbd>로 빠져나와요.
   빈 통합 문서로 시작했다면 `Sheet1`을 더블클릭해 `아이템`으로 바꿔요.

3. **이름 상자로 이동하기**
   이름 상자를 클릭하고 `F21`을 입력한 뒤 <kbd>Enter</kbd>를 눌러요. 20번째 아이템의 판매가 셀로 바로 이동해요.
   <kbd>Ctrl</kbd>+<kbd>Home</kbd>을 누르면 A1로, <kbd>Ctrl</kbd>+<kbd>End</kbd>를 누르면 데이터의 마지막 셀(G21)로 가요.

> **체크포인트** 수식 입력줄에 G21의 값 `가능`이 보이고, 이름 상자에 `G21`이 보이면 맞아요.

4. **(빈 파일로 시작했을 때만) 채우기 핸들로 ID 만들기**
   A1:G1에 `item_id, 아이템명, 분류, 등급, 획득처, 판매가, 거래가능`을 입력해요. A2에 `IT001`을 입력하고, 셀 오른쪽 아래 작은 네모(채우기 핸들)를 A21까지 끌어요.
   결과: `IT001`부터 `IT020`까지 숫자가 1씩 늘어나요. 나머지 열은 시작 파일의 값을 보고 입력해요.

5. **판매가에 단위 서식 붙이기**
   F2를 클릭하고 <kbd>Ctrl</kbd>+<kbd>Shift</kbd>+<kbd>↓</kbd>로 F21까지 선택해요. <kbd>Ctrl</kbd>+<kbd>1</kbd>로 **셀 서식** 창을 열고 **표시 형식 > 범주: 사용자 지정**을 고른 뒤, **형식** 칸에 아래를 입력하고 **확인**을 눌러요.

   ```text
   #,##0"메소"
   ```

   결과: `1500`이 `1,500메소`로 보여요. F2를 클릭하면 수식 입력줄에는 여전히 `1500`이 보여요.

6. **상태 표시줄로 합계 보기**
   F2:F21이 선택된 상태에서 화면 오른쪽 아래 상태 표시줄을 봐요. **평균, 개수, 합계**가 보여요.
   합계가 안 보이면 상태 표시줄을 마우스 오른쪽 버튼으로 눌러 **합계**에 체크해요.

> **체크포인트** 개수가 `20`으로 보이면 선택 범위가 맞아요. 합계 값은 마무리 문제에서 쓰니 적어 두세요.

7. **머리글 행 꾸미기**
   A1을 클릭하고 <kbd>Shift</kbd>+<kbd>Space</kbd>로 1행 전체를 선택해요. 그다음 아래를 차례로 적용해요.
   - <kbd>Ctrl</kbd>+<kbd>B</kbd>: 굵게
   - **홈 > 글꼴 > 채우기 색**: 진한 초록 등 어두운 색, **글꼴 색**: 흰색
   - **홈 > 맞춤 > 가운데 맞춤**

8. **열 너비 자동 맞춤**
   A열부터 G열까지 열 머리글(A, B, C…)을 드래그해 선택하고, <kbd>Alt</kbd> → <kbd>H</kbd> → <kbd>O</kbd> → <kbd>I</kbd>를 **하나씩 차례로** 눌러요. 메뉴로는 **홈 > 셀 > 서식 > 열 너비 자동 맞춤**이에요.
   결과: `예시 칭호 교환권`처럼 긴 이름도 잘리지 않고 보여요.

> **버전 차이 주의** 리본 단축키 글자는 리본 구성이 바뀌면 달라질 수 있어요. <kbd>Alt</kbd>를 누르면 탭마다 글자가 떠요. 화면에 뜨는 글자를 따라 누르면 돼요.

9. **테두리 넣기**
   A1을 클릭하고 <kbd>Ctrl</kbd>+<kbd>A</kbd>로 표 전체(A1:G21)를 선택해요. **홈 > 글꼴 > 테두리(▼) > 모든 테두리**를 눌러요.
   참고로 <kbd>Ctrl</kbd>+<kbd>Shift</kbd>+<kbd>&</kbd>는 **바깥 테두리**만 그려요.

10. **이동·선택·삭제 단축키 연습**
    `단축키연습` 시트로 가서(<kbd>Ctrl</kbd>+<kbd>Page Down</kbd>) 아래를 해 봐요.
    - B2 클릭 → <kbd>Ctrl</kbd>+<kbd>Shift</kbd>+<kbd>↓</kbd>: 어디서 멈추는지 확인해요 (12행이 비어 있어요)
    - 12행 아무 셀 클릭 → <kbd>Shift</kbd>+<kbd>Space</kbd>로 행 선택 → <kbd>Ctrl</kbd>+<kbd>-</kbd>로 행 삭제
    - 다시 B2 → <kbd>Ctrl</kbd>+<kbd>Shift</kbd>+<kbd>↓</kbd>: 이번엔 B31까지 한 번에 선택돼요
    - <kbd>Ctrl</kbd>+<kbd>Z</kbd>로 되돌리기, 셀을 고칠 땐 <kbd>F2</kbd>
    - <kbd>Ctrl</kbd>+<kbd>Space</kbd>는 열 전체 선택이에요

> **체크포인트** 빈 행을 지운 뒤 B2에서 <kbd>Ctrl</kbd>+<kbd>Shift</kbd>+<kbd>↓</kbd>를 누르면 상태 표시줄의 개수가 `30`이면 맞아요. 지우기 전에는 `10`에서 멈췄죠. 이게 "표 중간에 빈 행을 두지 않는" 이유예요.

11. **병합 셀 점검 후 저장**
    아이템 시트에서 <kbd>Ctrl</kbd>+<kbd>A</kbd> → **홈 > 맞춤 > 병합하고 가운데 맞춤(▼) > 셀 병합 취소**를 한 번 눌러 혹시 모를 병합을 풀어요. <kbd>Ctrl</kbd>+<kbd>S</kbd>로 저장해요.

> **체크포인트** 정답 파일(`day-01-answer.xlsx`)의 아이템 시트와 나란히 열어 비교해 보세요. 판매가 표시, 머리글 색, 테두리가 비슷하면 완성이에요.

## 실습 과제

혼자서 같은 파일에 **`보스보상` 시트**를 새로 만들어요 (<kbd>Shift</kbd>+<kbd>F11</kbd>로 새 시트).

- 머리글: `reward_id, 보스, 난이도, item_id, 수량, 판매가`
- 가상 보스 3종(`예시 보스 1~3`) × 보상 4개 = 12행
- `item_id`는 아이템 시트에 있는 ID만 써요 (예: `IT007`, `IT015`, `IT020`)
- `reward_id`는 채우기 핸들로 `RW001~RW012`
- 판매가 열에 `#,##0"메소"` 서식, 머리글 꾸미기, 모든 테두리, 열 너비 자동 맞춤
- 다 만든 뒤 판매가 열을 선택해 상태 표시줄 합계를 메모에 적어 두기

완성 기준: 병합 셀 없음 · 빈 행 없음 · 한 셀에 한 값 · 판매가가 숫자로 합계가 나옴.

## 자주 하는 실수와 해결법

| 증상 | 원인 | 해결 |
|---|---|---|
| 판매가 합계가 0이거나 상태 표시줄에 합계가 안 나와요 | `1500메소`처럼 단위를 글자로 입력했어요 | 숫자만 입력하고 단위는 사용자 지정 서식으로 붙여요 |
| 셀에 `#####`만 보여요 | 열 너비가 좁아 숫자가 안 들어가요 | 열 너비 자동 맞춤(<kbd>Alt</kbd> → <kbd>H</kbd> → <kbd>O</kbd> → <kbd>I</kbd>) |
| 채우기 핸들로 끌었더니 `IT001`만 반복돼요 | <kbd>Ctrl</kbd>을 누른 채 끌었어요 | <kbd>Ctrl</kbd>을 떼고 다시 끌거나, 끝난 뒤 나오는 **자동 채우기 옵션 > 연속 데이터 채우기** |
| <kbd>Ctrl</kbd>+<kbd>Shift</kbd>+<kbd>↓</kbd>가 중간에서 멈춰요 | 데이터 중간에 빈 셀·빈 행이 있어요 | 빈 행을 지우고, 빈 값은 비워 두지 말고 `0`이나 `-` 등 규칙을 정해요 |
| 저장할 때 "Excel 4.0 매크로 시트… 일반 워크시트로 변환됨" 창이 뜨고, 그 시트만 상태 표시줄 합계가 안 나와요 | 새 시트를 <kbd>Shift</kbd>+<kbd>F11</kbd> 대신 <kbd>Ctrl</kbd>+<kbd>F11</kbd>로 만들어 **매크로 시트**가 됐어요 (시트 탭 오른쪽 클릭 > 삽입에서 "MS Excel 4.0 매크로"를 골라도 같아요) | 저장 창에서 **예**를 누르면 일반 시트로 바뀌어요. 새 시트는 <kbd>Shift</kbd>+<kbd>F11</kbd> 또는 시트 탭 옆 **+** 버튼으로 만들어요 |
| 다른 시트의 같은 아이템 판매가가 서로 달라요 | 첫 값을 채우기 핸들로 끌어 같은 값이 복사됐어요 | 아이템 시트 값을 보고 고쳐요. 5일차 XLOOKUP 을 배우면 item_id 만으로 자동으로 가져올 수 있어요 |
| 사용자 지정 서식 입력 후 오류 창이 떠요 | 따옴표를 한글 따옴표(“ ”)로 입력했어요 | 영문 큰따옴표(`"`)로 다시 입력해요. 위 코드 블록을 복사하면 안전해요 |
