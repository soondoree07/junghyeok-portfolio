**속성 과정 1일차예요.** 원래 4~7일차(조건 집계, 조회, 텍스트·날짜, 입력 규칙)를 하루로 압축했어요. 개념은 표 한 장씩만 보고 바로 따라 하기로 넘어가요.

시작 파일에는 3일차까지 완성한 시트와 오늘 쓸 시트 세 개가 들어 있어요.

- `로그`: 가상 가을 이벤트 획득 로그 60행이에요. 로그번호, 날짜(2026-10-01 목요일부터 14일), 캐릭터ID, item_id, 수량, 획득처(출석·사냥·코인샵·보스)가 값으로 들어 있어요
- `집계`: A2:A21에 IT001~IT020, D1:G1에 획득처 네 개가 적혀 있어요. I1:I3에는 검산용 이름표가 있어요
- `레벨구간`: 하한 레벨과 등급 표(A:B), 판정해 볼 레벨 네 개(D2:D5)가 있어요

> **버전 차이 주의** `XLOOKUP`은 Microsoft 365와 Excel 2021 이상에만 있어요. 그 이하 버전은 `#NAME?`이 나와요. 이때는 아래 표의 `INDEX/MATCH`로 바꿔 써요.

## 개념 설명

### 조건 집계 — 조건에 맞는 것만 세고, 더하고, 평균 내기

| 함수 | 하는 일 | 쓰는 법 |
|---|---|---|
| `COUNTIF` | 조건에 맞는 칸 개수 | `=COUNTIF(찾을범위, 조건)` |
| `SUMIF` | 조건에 맞는 행의 합계 | `=SUMIF(찾을범위, 조건, 합계범위)` |
| `SUMIFS` | 조건 여러 개를 모두 만족하는 행의 합계 | `=SUMIFS(합계범위, 범위1, 조건1, 범위2, 조건2)` |
| `AVERAGEIF` | 조건에 맞는 행의 평균 | `=AVERAGEIF(찾을범위, 조건, 평균범위)` |

**가장 많이 헷갈리는 것:** 합계 범위 위치가 달라요. `SUMIF`는 **맨 뒤**, `SUMIFS`는 **맨 앞**이에요.

조건 쓰는 법은 세 가지만 알면 돼요.

| 조건 | 뜻 |
|---|---|
| `"보스"` 또는 `A2` | 값이 같은 것 |
| `">="&K1` | K1 이상인 것. 연산자는 따옴표 안, 셀은 `&`로 붙여요 |
| `"*쿠폰*"` | "쿠폰"이 들어간 모든 글자. `*`는 "아무 글자나" |

### 조회 — ID로 다른 표의 값 가져오기

| 방식 | 수식 모양 | 특징 |
|---|---|---|
| `XLOOKUP` | `=XLOOKUP(찾을값, 찾을범위, 가져올범위, "없을때값")` | 오늘 주로 쓸 방식. 방향 제한 없음 |
| `VLOOKUP` | `=VLOOKUP(찾을값, 표, 열번호, FALSE)` | 옛날 방식. 찾는 열이 맨 왼쪽이어야 하고, 열을 끼워 넣으면 깨져요 |
| `INDEX/MATCH` | `=INDEX(가져올범위, MATCH(찾을값, 찾을범위, 0))` | 옛 버전 호환용. XLOOKUP과 같은 일을 해요 |

회사 파일에서 `VLOOKUP`을 보면 "XLOOKUP의 옛날 버전"이라고 읽으면 돼요.

**근사 일치:** `XLOOKUP`의 다섯 번째 인수에 `-1`을 넣으면 "같은 값이 없으면 **바로 아래 값**"을 찾아요. 레벨 59는 하한표에서 1과 60 사이라 1 행(D 등급)을 돌려줘요. 레벨 구간, 확률 구간 판정에 써요.

### 텍스트·날짜·반올림

| 함수 | 예 | 결과 |
|---|---|---|
| `TEXT(날짜,"aaa")` | 2026-10-01 | `목` |
| `WEEKDAY(날짜,2)` | 토요일 | `6` (월=1 … 일=7) |
| `ROUNDUP(값,0)` | 4.29 | `5` (무조건 올림) |
| `ROUNDDOWN(값,0)` | 4.99 | `4` (무조건 내림) |

날짜는 엑셀 안에서 **숫자(일련번호)**예요. 그래서 `날짜+7`이 일주일 뒤예요.

### 입력 규칙 — 잘못된 값 막기, 눈에 띄게 하기

- **데이터 유효성 검사(드롭다운):** 정해진 값만 고를 수 있게 막아요. **데이터 > 데이터 도구 > 데이터 유효성 검사**
- **조건부 서식(수식):** 수식이 TRUE인 칸에 색을 칠해요. **홈 > 조건부 서식 > 새 규칙 > 수식을 사용하여…**
- 수식 규칙은 **선택 범위의 첫 행 기준**으로 써요. 행 전체를 칠하려면 열만 고정(`$F2`)해요

## 따라 하기

1. **시작 파일 열고 저장**
   시작 파일을 열고 <kbd>F12</kbd>로 `excel-04_log-summary.xlsx`로 저장해요. `집계` 시트로 가요.

2. **아이템별 획득 횟수 (COUNTIF)**
   B2에 아래 수식을 넣고 채우기 핸들을 더블클릭해 B21까지 채워요.

   ```text
   =COUNTIF(로그!$D:$D,A2)
   ```

   `로그!$D:$D`는 "로그 시트의 D열 전체"예요. 다른 시트를 가리킬 땐 `시트이름!`을 앞에 붙여요. 수식 입력 중에 로그 시트 탭을 눌러 D열 머리글을 클릭하면 자동으로 들어가요.

> **체크포인트** B2(IT001) = `3`, B7(IT006) = `6`, B15(IT014) = `0`이면 맞아요.

3. **아이템별 수량 합계 (SUMIF)**
   C2에 넣고 C21까지 채워요.

   ```text
   =SUMIF(로그!$D:$D,A2,로그!$E:$E)
   ```

> **체크포인트** C2 = `8`, C11(IT010) = `22`, C21(IT020) = `16`이에요.

4. **아이템 × 획득처 표 (SUMIFS + 혼합 참조)**
   D2에 아래 수식을 넣어요. 3일차 배율표처럼 `$A2`(열 고정)와 `D$1`(행 고정)을 써요.

   ```text
   =SUMIFS(로그!$E:$E,로그!$D:$D,$A2,로그!$F:$F,D$1)
   ```

   D2를 복사해 D2:G21에 붙여넣어요. 수식 하나로 80칸이 채워져요.

> **체크포인트** 2행(IT001)이 D2:G2 = `5, 0, 2, 1`이고, 합이 C2의 `8`과 같아요.

5. **검산**
   J1에 `=SUM(로그!$E:$E)`, J2에 `=SUM(C2:C21)`, J3에 `=IF(J1=J2,"OK","확인 필요")`를 넣어요.
   집계표를 만들면 **항상 원본 합계와 맞춰 봐요.** 빠진 ID나 오타가 있으면 여기서 드러나요.

> **체크포인트** J1 = J2 = `177`, J3 = `OK`예요.

6. **로그에 아이템명·판매가 붙이기 (XLOOKUP)**
   `로그` 시트로 가요. G1에 `아이템명`, H1에 `판매가`, I1에 `메소환산`을 입력해요.
   G2, H2, I2에 아래 수식을 넣고 각각 61행까지 채워요.

   ```text
   =XLOOKUP(D2,아이템!$A:$A,아이템!$B:$B,"없음")
   =XLOOKUP(D2,아이템!$A:$A,아이템!$F:$F,0)
   =E2*H2
   ```

> **체크포인트** G2 = `예시 주문서 B`, H2 = `4800`, I2 = `14400`(수량 3 × 4800)이에요.

7. **없는 ID 넣어 보기**
   D2를 `IT999`로 바꿔요. G2가 `없음`, H2가 `0`이 돼요. 확인했으면 <kbd>Ctrl</kbd>+<kbd>Z</kbd>로 되돌려요.
   네 번째 인수(`"없음"`)를 빼면 `#N/A` 오류가 나요. 3일차 IFS의 `TRUE,기본값`과 같은 역할이에요.

8. **요일과 주말 (TEXT, WEEKDAY)**
   J1에 `요일`, K1에 `주말여부`를 입력하고 아래 수식을 넣어 61행까지 채워요.

   ```text
   =TEXT(B2,"aaa")
   =IF(WEEKDAY(B2,2)>=6,"주말","평일")
   ```

   3일차에는 MOD로 요일을 계산했어요. 실제 날짜가 있으면 이렇게 바로 구해요.

> **체크포인트** J2 = `목`, K4(10-03) = `주말`이에요. K열에서 `주말`은 모두 `18`개예요(<kbd>Ctrl</kbd>+<kbd>Shift</kbd>+<kbd>L</kbd> 필터로 세어 봐도 돼요).

9. **레벨 구간 판정 (근사 일치)**
   `레벨구간` 시트로 가요. E2에 넣고 E5까지 채워요.

   ```text
   =XLOOKUP(D2,$A$2:$A$6,$B$2:$B$6,"",-1)
   ```

> **체크포인트** 59 → `D`, 60 → `C`, 139 → `B`, 250 → `S`예요. 마지막 `-1`을 빼면 정확히 같은 값만 찾아서 59·139·250은 빈 칸이 돼요.

10. **필요 코인 (ROUNDUP)**
    `아이템` 시트 H1에 `필요코인`, H2에 아래 수식을 넣고 H21까지 채워요. 코인 1개 = 350메소로 가정해요.

    ```text
    =ROUNDUP(F2/350,0)
    ```

    1500 ÷ 350 = 4.29예요. `ROUND`면 4코인이라 운영이 손해를 봐요. 가격 계산은 보통 **올림**이에요.

> **체크포인트** H2 = `5`, H9(IT008, 62000) = `178`이에요.

11. **드롭다운 (데이터 유효성 검사)**
    `로그` 시트 F2:F61을 선택하고 **데이터 > 데이터 유효성 검사**를 열어요.
    - 제한 대상: **목록**
    - 원본: `출석,사냥,코인샵,보스` (쉼표로 구분, 따옴표 없이)
    - **오류 메시지** 탭: 스타일 **중지**, 내용 `목록에 있는 획득처를 골라 주세요`

    F2에 `상점`을 입력해 막히는지 확인하고 **취소**를 눌러요.

12. **조건부 서식 두 개**
    - `로그` 시트 A2:K61 선택 → **홈 > 조건부 서식 > 새 규칙 > 수식을 사용하여 서식을 지정할 셀 결정** → `=$F2="보스"` → 채우기 연노랑. 보스 행 전체가 칠해져요
    - `아이템` 시트 A2:A21 선택 → 같은 메뉴 → `=COUNTIF($A:$A,$A2)>1` → 채우기 빨강. A3을 `IT001`로 바꿔 두 칸이 빨개지는지 보고 <kbd>Ctrl</kbd>+<kbd>Z</kbd>

    <kbd>Ctrl</kbd>+<kbd>S</kbd>로 저장해요.

> **체크포인트** 정답 파일(`day-04-answer.xlsx`)과 나란히 열어 `집계`, `로그`, `레벨구간` 시트의 같은 셀을 비교해 보세요.

## 실습 과제

같은 파일에서 아래를 채워요. 새 시트는 만들지 않아요.

- `집계` 시트 L1:N1에 `획득처, 로그수, 평균수량` 머리글을 넣고, L2:L5에 `출석, 사냥, 코인샵, 보스`를 적어요
- M열: 획득처별 로그 행 수 (`COUNTIF`)
- N열: 획득처별 평균 수량, 소수 둘째 자리 반올림 (`ROUND` + `AVERAGEIF`)
- L7에 `쿠폰 아이템 수`, M7에 아이템 시트 아이템명 중 "쿠폰"이 들어간 개수 (`COUNTIF` + 와일드카드)
- `로그` 시트 L1에 `등급`, L열에 아이템 시트의 등급(D열)을 XLOOKUP으로 가져오기

완성 기준: M2:M5 = `11, 16, 17, 16` (합 60) · N2:N5 = `2.82, 3.25, 2.53, 3.19` · M7 = `2` · 로그 L2 = `에픽`.

## 자주 하는 실수와 해결법

| 증상 | 원인 | 해결 |
|---|---|---|
| SUMIFS 결과가 이상하거나 오류예요 | SUMIF 습관대로 합계 범위를 맨 뒤에 넣었어요 | SUMIFS는 **합계 범위가 맨 앞**이에요 |
| `">=K1"` 조건이 아무것도 못 찾아요 | 따옴표 안의 K1은 셀이 아니라 글자 "K1"이에요 | `">="&K1`처럼 연산자만 따옴표에 넣고 `&`로 셀을 붙여요 |
| 옆으로 복사했더니 SUMIFS가 엉뚱한 열을 더해요 | `로그!E:E`에 `$`가 없어서 옆으로 복사할 때 F, G열로 밀렸어요 | 범위는 `로그!$E:$E`처럼 고정해요 |
| XLOOKUP이 `#N/A`예요 | ID가 없거나, 앞뒤 공백이 있거나, 숫자/글자 형식이 달라요 | 네 번째 인수에 `"없음"`을 넣고, 없음이 뜬 ID를 눈으로 확인해요 |
| 근사 일치가 틀린 등급을 줘요 | 하한표가 작은 값부터 정렬돼 있지 않아요 | 하한 레벨을 오름차순으로 정리해요 |
| `TEXT(B2,"aaa")`가 `aaa`로 나와요 | B2가 날짜가 아니라 글자예요 | B2 서식을 날짜로 바꾸거나 날짜를 다시 입력해요 |
| 조건부 서식이 한 칸만 칠해지거나 엇갈려요 | 수식을 첫 행 기준으로 안 썼거나 `$` 위치가 틀렸어요 | 범위 첫 행(2행) 기준으로 `$F2`처럼 열만 고정해요 |
