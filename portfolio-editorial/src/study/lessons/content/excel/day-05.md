**속성 과정 2일차예요.** 원래 8~10일차(이름 정의와 테이블 설계, 피벗 테이블, 차트)를 하루로 압축했어요. 단계마다 **풀어 보기**에 수식을 조각내 설명해 뒀어요. 수식이 이해 안 되면 거기부터 읽어요.

시작 파일에는 4일차 정답 상태에 시트가 더해져 있어요.

- `설정`: 이름·값·설명 표예요. 주말배율 `2`, 코인가치 `350`, 기본값 `100`, 지수 `2`, 성장률 `1.2`(B2:B6)
- `보상그룹`: RG001~RG004 그룹 4개 (출석 7일차, 출석 14일차, 코인샵, 보스 처치)
- `보상`: 보상 12행(reward_id, group_id, item_id, 수량). **일부러 잘못 넣은 행이 두 개** 있어요
- `곡선`: A2:A51에 레벨 1~50

> **정답 파일 안내** 피벗 테이블과 차트는 실습 파일 만드는 프로그램이 지원하지 않아서 정답 파일에 없어요. 레슨의 체크포인트 값으로 확인해요.

## 개념 설명

### 이름 정의 — 셀에 이름 붙이기

`$I$1` 대신 `주말배율`이라고 쓰면 수식만 읽어도 뜻을 알 수 있어요. 이름은 **어느 시트에서 써도 같은 칸**을 가리켜서 `$`도 시트 이름도 필요 없어요.

| 쓰는 법 | 수식 | 읽을 때 |
|---|---|---|
| 셀 주소 | `=F2/설정!$B$3` | "설정 시트 B3이 뭐였더라?" 하고 찾아가야 해요 |
| 이름 | `=F2/코인가치` | 바로 "코인가치로 나눈다"로 읽혀요 |

- 이름은 **이미 절대 참조**예요. 아래로 채워도, 다른 시트에 붙여도 늘 `설정!$B$3`을 가리켜요. 그래서 `$`를 안 붙여요
- 만드는 법: 셀 선택 → 왼쪽 위 **이름 상자**(수식 입력줄 왼쪽, 평소 `B2`처럼 셀 주소가 보이는 칸)에 이름 입력 → <kbd>Enter</kbd>
- 목록 보기·고치기·지우기: <kbd>Ctrl</kbd>+<kbd>F3</kbd> (**수식 > 이름 관리자**)
- 이름 규칙: 띄어쓰기 안 돼요. `A1`, `R2C3`처럼 셀 주소로 보이는 이름도 안 돼요. 한글은 돼요
- 기획 파일에서는 배율·확률·단가 같은 **설정값을 한 시트에 모으고 이름을 붙여요.** 밸런스를 조정할 때 그 시트만 고치면 모든 수식이 따라 바뀌어요

### 테이블 설계 — ID로 표를 연결하기

| 용어 | 뜻 | 오늘 예 |
|---|---|---|
| 기본 키(PK) | 그 표에서 행 하나를 딱 가리키는 ID. 겹치거나 재사용하면 안 돼요 | 아이템의 `item_id`, 보상그룹의 `group_id` |
| 외래 키(FK) | 다른 표의 ID를 가리키는 열 | 보상의 `group_id`, `item_id` |
| 1:N | 하나에 여러 개가 딸린 관계 | 보상그룹 1개에 보상 행 여러 개 |

오늘 표 세 개는 이렇게 연결돼요.

```text
보상그룹 (group_id)  1 ──── N  보상 (group_id, item_id)  N ──── 1  아이템 (item_id)
  RG001 출석 7일차              RW001  RG001  IT002  1개           IT002 예시 주문서 B
                                RW002  RG001  IT009 20개           IT009 회복 물약(소)
```

- 보상 행 하나는 "어느 그룹에(group_id) 어떤 아이템을(item_id) 몇 개" 주는지 적은 거예요
- 보상 표에 아이템 **이름**을 직접 적지 않고 `item_id`만 두는 이유: 이름이 바뀌어도 아이템 표 한 곳만 고치면 돼요. 이름이 필요하면 4일차처럼 XLOOKUP으로 가져와요
- 대신 **없는 ID를 가리키는 행**이 생길 수 있어요. 오타로 `IT021`(없는 아이템)을 적으면 XLOOKUP이 못 찾아요. 그래서 참조 검사를 따로 해요

### 피벗 테이블 — 수식 없이 집계표 만들기

4일차에 SUMIFS로 만든 아이템 × 획득처 표를 **끌어다 놓기만으로** 만드는 기능이에요.

| 영역 | 넣는 것 | 오늘 예 | SUMIFS로 치면 |
|---|---|---|---|
| 행 | 세로로 나열할 항목 | 획득처 | A열 머리(`$A2`) |
| 열 | 가로로 나열할 항목 | (처음엔 비워 둠) | 1행 머리(`D$1`) |
| 값 | 계산할 숫자와 방식 | 수량 합계 | 합계 범위(`로그!$E:$E`) |
| 필터 | 전체를 걸러 볼 조건 | 캐릭터ID | 조건 하나 더 |

- **언제 피벗, 언제 수식:** 빨리 훑어보고 이리저리 바꿔 볼 땐 피벗이 빨라요. 다른 수식이 그 값을 계속 써야 하거나, 표 모양이 고정이어야 하면 SUMIFS가 안전해요
- 원본에 행을 추가했으면 **데이터 > 모두 새로 고침**을 눌러야 피벗이 바뀌어요. 수식과 달리 자동으로 안 바뀌어요

### 차트 — 목적에 맞게 고르기

| 차트 | 언제 | 예 |
|---|---|---|
| 막대 | 항목끼리 크기 비교 | 획득처별 수량 |
| 선 | 순서대로 변하는 값 | 일차별 획득량 |
| 분산형 | X가 실제 숫자일 때(레벨, 시간) | 레벨별 필요 경험치 |

**선형과 분산형의 차이:** 선형 차트는 X를 그냥 "1번째, 2번째..." 칸으로 봐요. 레벨이 1, 2, 5, 10처럼 띄엄띄엄이어도 같은 간격으로 그려요. 분산형은 X를 **실제 숫자**로 봐서 1과 2 사이보다 5와 10 사이를 더 넓게 그려요. 레벨·시간처럼 숫자 자체가 의미 있으면 분산형을 써요.

성장 곡선은 세 가지 모양만 알면 돼요. 오늘은 기본값 100, 지수 2, 성장률 1.2예요.

| 모양 | 수식 | 레벨 1 | 레벨 10 | 레벨 50 | 특징 |
|---|---|---|---|---|---|
| 선형 | `기본값 × 레벨 × 10` | 1,000 | 10,000 | 50,000 | 한 레벨마다 같은 양(1,000)씩 늘어요 |
| 다항 | `기본값 × 레벨^지수` | 100 | 10,000 | 250,000 | 갈수록 가팔라져요 |
| 지수 | `기본값 × 성장률^레벨` | 120 | 619 | 910,044 | 처음엔 느리다가 어느 순간 폭발해요 |

- `^`는 거듭제곱이에요. `레벨^2` = 레벨 × 레벨, `1.2^3` = 1.2 × 1.2 × 1.2
- 다항은 **레벨이 밑**, 지수는 **레벨이 지수 자리**예요. 이 차이 때문에 지수는 레벨이 오를 때마다 "1.2배씩" 곱해져서 결국 다항을 앞질러요
- 게임에서는 초반을 빠르게, 후반을 길게 만들려고 다항이나 지수를 써요. 지수는 후반이 너무 가팔라서 구간을 나눠 쓰는 경우가 많아요

## 따라 하기

1. **시작 파일 열고 저장**
   시작 파일을 열고 <kbd>F12</kbd>로 `excel-05_table-design.xlsx`로 저장해요. `설정` 시트로 가요.

2. **설정값에 이름 붙이기**
   B2를 클릭하고 이름 상자(수식 입력줄 왼쪽, 지금 `B2`라고 보이는 칸)에 `주말배율`을 입력하고 <kbd>Enter</kbd>를 눌러요.
   같은 방법으로 B3 = `코인가치`, B4 = `기본값`, B5 = `지수`, B6 = `성장률`을 만들어요. A열에 적힌 이름 그대로 쓰면 돼요.

**풀어 보기: 이름 상자**

- 이름 상자를 클릭하면 `B2` 글자가 파랗게 선택돼요. 그 상태에서 바로 `주말배율`을 치면 덮어써져요
- **반드시 <kbd>Enter</kbd>로 끝내요.** 입력하고 다른 칸을 클릭하면 이름이 안 만들어져요
- 잘 만들어졌는지는 B2를 다시 클릭해 보면 알아요. 이름 상자에 `B2` 대신 `주말배율`이 보여요
- 잘못 만들었으면 <kbd>Ctrl</kbd>+<kbd>F3</kbd> → 그 이름 선택 → **삭제**하고 다시 만들어요

> **체크포인트** <kbd>Ctrl</kbd>+<kbd>F3</kbd>를 누르면 이름 관리자에 다섯 개가 보이고, 참조 대상이 `=설정!$B$2`~`$B$6`이에요.

3. **이름으로 수식 바꾸기**
   `아이템` 시트 H2의 `=ROUNDUP(F2/350,0)`을 아래처럼 고치고 H21까지 다시 채워요.

   ```text
   =ROUNDUP(F2/코인가치,0)
   ```

   결과는 그대로 `5`예요. 이제 `설정` 시트 B3을 `500`으로 바꿔 보세요. H열이 모두 바뀌어요(H2 = `3`). 확인했으면 `350`으로 돌려놓아요.

**풀어 보기: `ROUNDUP(F2/코인가치,0)`**

| 조각 | 뜻 |
|---|---|
| `F2` | 이 아이템의 판매가 (메소) |
| `/코인가치` | 코인 1개 = 350메소로 나눠요 → "코인 몇 개 값인가" |
| `ROUNDUP(...,0)` | 소수점 아래를 **무조건 올려** 정수로 만들어요 |

- H2: 판매가 1,500 ÷ 350 = 4.28... → 올려서 `5`. 코인 4개로는 모자라니 5개가 필요하다는 뜻이에요
- ROUND(반올림)였다면 4가 돼서 손해 보는 가격이 돼요. 가격·필요 개수는 보통 **올림**을 써요
- 원래 수식의 `350`처럼 수식 안에 박힌 숫자를 **매직 넘버**라고 해요. 값을 바꾸려면 수식을 다 찾아 고쳐야 해서 위험해요. 이름으로 바꾸면 설정 한 칸만 고치면 돼요

4. **보상 가치 구하기 (다른 표에서 가격 가져오기)**
   `보상` 시트로 가요. E2에 아래 수식을 넣고 E13까지 채워요.

   ```text
   =D2*XLOOKUP(C2,아이템!$A:$A,아이템!$F:$F,0)
   ```

**풀어 보기: `D2*XLOOKUP(C2,아이템!$A:$A,아이템!$F:$F,0)`**

뒤쪽 XLOOKUP부터 읽어요. 4일차 로그 시트 판매가(H열)와 똑같은 수식이에요.

| 조각 | 뜻 |
|---|---|
| `C2` | 찾을값: 이 보상 행의 item_id |
| `아이템!$A:$A` | 찾을범위: 아이템 시트 ID 열 |
| `아이템!$F:$F` | 가져올범위: 같은 줄의 판매가 |
| `0` | 없을때값: 못 찾으면 0 |
| `D2*` | 그 판매가에 이 행의 수량을 곱해요 |

말로 풀면 "이 행 아이템의 판매가 × 수량 = 이 보상 한 줄의 메소 가치"예요. 4일차에는 판매가(H열)와 메소환산(I열)을 두 칸에 나눠 했는데, 여기선 한 칸에 합쳤어요.

> **체크포인트** E2(RW001, 예시 주문서 B 1개) = `4800`, E3(회복 물약(소) 20개) = `1000`이에요. E7은 `0`이에요. 왜 0인지 다음 단계에서 찾아요.

5. **참조 검사 (FK가 진짜 있는지)**
   F2에 아래 수식을 넣고 F13까지 채워요.

   ```text
   =IF(COUNTIF(아이템!$A:$A,C2)=0,"없는 아이템",IF(COUNTIF(보상그룹!$A:$A,B2)=0,"없는 그룹",""))
   ```

   A2:F13을 선택하고 조건부 서식 수식 규칙 `=$F2<>""`로 빨간 채우기를 걸어요.

**풀어 보기: 참조 검사 수식**

IF 안에 IF가 하나 더 들어 있어요(3일차 IFS를 IF로 쓴 모양). 바깥부터 차례로 읽어요.

```text
=IF( COUNTIF(아이템!$A:$A,C2)=0 , "없는 아이템" ,
     IF( COUNTIF(보상그룹!$A:$A,B2)=0 , "없는 그룹" , "" ) )
```

| 순서 | 검사 | 맞으면 | 아니면 |
|---|---|---|---|
| 1 | 아이템 시트 ID 열에 C2(item_id)가 0번 나오나? | `없는 아이템` | 2번 검사로 |
| 2 | 보상그룹 시트 ID 열에 B2(group_id)가 0번 나오나? | `없는 그룹` | `""`(빈 칸 = 문제 없음) |

- `COUNTIF(범위, 값)`은 4일차에 "몇 번 나오나"를 셀 때 썼어요. 여기선 그 개수가 **0이면 = 상대 표에 그 ID가 없다**는 뜻으로 써요
- 정상이면 빈 칸이 나오게 해서, 문제 있는 행만 글자가 보이게 했어요

**조건부 서식 `=$F2<>""`**

- `<>`는 "같지 않다", `""`는 "빈 칸"이에요. 합치면 "F열이 비어 있지 않으면" → 문제 있는 행이에요
- `$F2`: 열은 F로 잠그고 행은 움직여요. A2:F13 전체에 규칙을 걸어도 각 칸이 **자기 행의 F열**을 봐서 행 전체가 빨개져요. 4일차 보스 행 칠하기(`$F2="보스"`)와 같은 원리예요
- 만드는 법: A2:F13 선택 → **홈 > 조건부 서식 > 새 규칙 > 수식을 사용하여 서식을 지정할 셀 결정** → 수식 칸에 `=$F2<>""` → **서식 > 채우기**에서 빨강

> **체크포인트** 7행(RW006, IT021) = `없는 아이템`, 12행(RW011, RG005) = `없는 그룹`이 빨갛게 칠해져요. 나머지는 빈 칸이에요.

6. **그룹별 보상 수와 총가치 (1:N 집계)**
   `보상그룹` 시트 C2, D2에 아래 수식을 넣고 5행까지 채워요.

   ```text
   =COUNTIF(보상!$B:$B,A2)
   =SUMIF(보상!$B:$B,A2,보상!$E:$E)
   ```

**풀어 보기: 1:N 집계**

"1" 쪽(보상그룹) 한 행에서 "N" 쪽(보상)의 여러 행을 세고 더해요. 4일차 집계 시트 B·C열과 같은 수식이에요.

| 수식 | 말로 풀면 |
|---|---|
| `COUNTIF(보상!$B:$B,A2)` | 보상 시트 group_id 열에서 RG001이 몇 줄인가 → 이 그룹의 보상 개수 |
| `SUMIF(보상!$B:$B,A2,보상!$E:$E)` | 보상 시트 group_id가 RG001인 줄의 가치(E열)를 더해요 → 이 그룹 총가치 |

- SUMIF 순서: **조건 볼 곳 → 조건 → 더할 곳**. 더할 곳(E열)이 맨 뒤예요
- `A2`에 `$`가 없는 건 아래로 채울 때 A3, A4로 바뀌어 그룹마다 따로 세야 해서예요

> **체크포인트** C2:C5 = `3, 2, 3, 3`, D2:D5 = `8300, 12600, 7000, 56000`이에요. RG003이 작은 건 없는 아이템 행이 0으로 계산됐기 때문이에요.

7. **피벗 테이블 만들기**
   `로그` 시트 안 아무 칸이나 클릭하고 **삽입 > 피벗 테이블 > 새 워크시트 > 확인**을 눌러요. 새 시트 이름을 `피벗`으로 바꿔요(시트 탭 더블클릭).
   오른쪽 필드 목록에서 `획득처`를 **행**으로, `수량`을 **값**으로 끌어다 놓아요.

**풀어 보기: 피벗 화면 읽기**

- 로그 표 안을 클릭해 두면 엑셀이 표 범위(A1:K61)를 알아서 잡아요. 창에 범위가 `로그!$A$1:$K$61`처럼 보이면 맞아요
- 새 시트 오른쪽에 **피벗 테이블 필드** 창이 떠요. 위쪽은 로그의 머리글 목록, 아래쪽은 네 칸(필터·열·행·값)이에요
- 필드 창이 안 보이면 피벗 안을 클릭해요. 피벗 밖을 누르면 창이 사라져요
- 끌어다 놓은 결과를 SUMIFS로 쓰면 `=SUMIF(로그!$F:$F,"출석",로그!$E:$E)`와 같아요. 피벗은 이걸 획득처마다 알아서 만들어 줘요
- 잘못 놓았으면 아래 칸에서 그 항목을 창 밖으로 끌어내면 빠져요

> **체크포인트** 출석 `31`, 사냥 `52`, 코인샵 `43`, 보스 `51`, 총합계 `177`이에요. 4일차 집계표 D~G열 합계와 같아요.

8. **비율로 바꿔 보기**
   값 영역의 `합계 : 수량`을 클릭 → **값 필드 설정 > 값 표시 형식 > 총합계 비율**을 골라요.
   결과: 보스가 `28.81%`예요. 확인했으면 같은 메뉴에서 **계산 없음**으로 되돌려요.

**풀어 보기: 총합계 비율**

- 각 칸 ÷ 총합계예요. 보스 51 ÷ 177 = 0.2881 → `28.81%`
- 수식으로 하려면 비율 열을 따로 만들어야 하는데, 피벗은 표시 방식만 바꿔요. 원래 숫자는 그대로라 **계산 없음**으로 언제든 돌아와요
- 기획서에서 "획득량의 약 29%가 보스에서 나온다"처럼 쓸 때 이 값을 써요

9. **피벗 차트 (막대)**
   피벗 안을 클릭하고 **피벗 테이블 분석 > 피벗 차트 > 세로 막대형**을 골라요. 차트 제목을 클릭해 `획득처별 수량`으로 바꿔요.
   피벗에서 `캐릭터ID`를 **필터**로 끌어다 놓고 하나만 골라 보면 차트도 같이 바뀌어요.

**풀어 보기: 피벗 차트**

- **피벗 테이블 분석** 탭은 피벗 안을 클릭해야 위쪽 리본에 나타나요
- 일반 차트와 다른 점: 피벗을 바꾸면(필터, 행 추가) 차트가 같이 바뀌어요
- 필터 칸에 `캐릭터ID`를 넣으면 피벗 위쪽 B1 근처에 `(모두)` 드롭다운이 생겨요. 거기서 캐릭터 하나를 고르면 그 캐릭터 로그만 집계돼요. SUMIFS에 조건을 하나 더 붙인 것과 같아요
- 다 봤으면 필터를 `(모두)`로 돌려놓아요

10. **성장 곡선 세 개 만들기**
    `곡선` 시트 B2, C2, D2에 아래 수식을 넣고 51행까지 채워요.

    ```text
    =기본값*A2*10
    =ROUND(기본값*A2^지수,0)
    =ROUND(기본값*성장률^A2,0)
    ```

**풀어 보기: 성장 곡선 수식**

A2 = 레벨이에요. 이름(기본값·지수·성장률)은 설정 시트 값을 가리켜요.

| 칸 | 수식 | 레벨 2일 때 계산 |
|---|---|---|
| B (선형) | `기본값*A2*10` | 100 × 2 × 10 = 2,000 |
| C (다항) | `ROUND(기본값*A2^지수,0)` | 100 × 2² = 100 × 4 = 400 |
| D (지수) | `ROUND(기본값*성장률^A2,0)` | 100 × 1.2² = 100 × 1.44 = 144 |

- 계산 순서: `^`(거듭제곱)가 `*`(곱하기)보다 먼저예요. `기본값*A2^지수`는 `기본값*(A2^지수)`로 계산돼요
- ROUND(...,0)은 경험치를 정수로 만들려고 붙였어요. 선형은 원래 정수라 안 붙였어요
- 이름에는 `$`가 필요 없고, `A2`만 아래로 내려가며 A3, A4로 바뀌어요

> **체크포인트** 50레벨(51행) = `50000`, `250000`, `910044`예요. 40레벨까지는 다항이 크고, **41레벨에서 지수가 다항을 처음 추월**해요. 레벨 41은 42행이에요: C42 = `168100`, D42 = `176373`.

11. **분산형 차트와 로그 축**
    A1:D51을 선택하고 **삽입 > 분산형 > 곡선이 있는 분산형**을 골라요.
    지수 곡선이 너무 커서 나머지가 바닥에 붙어 보여요. 세로 축을 더블클릭 → **축 서식 > 로그 눈금 간격**을 체크해요. 세 곡선이 한눈에 비교돼요.
    `설정` 시트 B5(지수)를 `2.5`로 바꿔 차트가 어떻게 변하는지 보고 `2`로 돌려놓은 뒤 저장해요.

**풀어 보기: 로그 축**

- 보통 축은 눈금이 0, 200,000, 400,000...처럼 **같은 양씩** 늘어요. 910,044까지 그리면 1,000짜리 값은 바닥에 붙어 안 보여요
- 로그 축은 눈금이 1, 10, 100, 1,000, 10,000...처럼 **10배씩** 늘어요. 작은 값과 큰 값이 한 화면에 같이 보여요
- 로그 축에서는 지수 곡선이 **직선**으로 보여요(매 레벨 1.2배씩 일정하게 커지니까). 기울기가 일정하면 "같은 비율로 커진다"는 뜻이에요
- 0이나 음수는 로그 축에 못 그려요. 그래서 레벨 1부터 시작하는 표를 썼어요
- 축 서식 창은 오른쪽에 떠요. **축 옵션**(막대 그래프 모양 아이콘) 안에 **로그 눈금 간격** 체크 칸이 있어요

## 실습 과제

같은 파일에서 5단계에서 찾은 오류 두 개를 고치고, 피벗을 한 단계 더 나눠 봐요.

- `보상` 시트 RW006의 item_id `IT021`을 `IT018`(예시 의자)로 고쳐요
- `보상그룹` 시트 6행에 `RG005`, `이벤트 상자`를 추가하고 C6, D6에 위쪽 수식을 채워요
- `피벗` 시트에서 행에 `획득처`, **열**에 `요일`을 더해 요일별로도 나눠 봐요

**힌트**

- 첫 번째: 보상 시트 C7 칸만 고치면 돼요. 고치는 순간 E7(가치)과 F7(검사)이 자동으로 바뀌어요. 수식은 손대지 않아요
- 두 번째: A6 `RG005`, B6 `이벤트 상자`를 입력하고 C5:D5를 선택해 채우기 핸들을 6행까지 끌어요. 그러면 수식의 `A5`가 `A6`으로 바뀌어 RG005를 세요. 보상 시트 12행의 `없는 그룹`도 이제 사라져요(상대 표에 RG005가 생겼으니까)
- 세 번째: 피벗 안을 클릭 → 필드 창에서 `요일`을 **열** 칸으로 끌어요. 요일은 4일차에 로그 J열에 만든 그 열이에요. 피벗이 "획득처 × 요일" 표가 돼요. 4일차 SUMIFS 아이템 × 획득처 표를 피벗으로 만든 것과 같은 모양이에요
- 필드 목록에 `요일`이 안 보이면 **피벗 테이블 분석 > 데이터 원본 변경**에서 범위가 K열까지 잡혔는지 확인하고 **모두 새로 고침**을 눌러요

완성 기준: 보상 F열이 모두 빈 칸(빨간 행 없음) · 보상그룹 D4(RG003) = `14000`, D6(RG005) = `1500` · 피벗에 요일 열이 생김.

## 자주 하는 실수와 해결법

| 증상 | 원인 | 해결 |
|---|---|---|
| 이름 상자에 이름을 넣었는데 안 만들어져요 | <kbd>Enter</kbd> 대신 다른 칸을 클릭했어요 | 이름 입력 후 꼭 <kbd>Enter</kbd>를 눌러요 |
| 이름 정의가 거부돼요 | 이름에 띄어쓰기가 있거나, `A1`처럼 셀 주소 모양이에요 | 띄어쓰기 없이 `주말배율`, `코인가치`처럼 지어요 |
| 수식에서 `#NAME?`이 나와요 | 이름을 오타로 쓰거나 아직 정의하지 않았어요 | <kbd>Ctrl</kbd>+<kbd>F3</kbd>로 이름을 확인해요 |
| 이름을 잘못된 칸에 붙였어요 | B2가 아닌 칸을 선택한 채 이름을 넣었어요 | <kbd>Ctrl</kbd>+<kbd>F3</kbd>에서 그 이름을 골라 아래 **참조 대상**을 고치거나 지우고 다시 만들어요 |
| 참조 검사 수식이 모든 행에 `없는 아이템`이라고 해요 | `아이템!$A:$A` 대신 다른 열을 골랐거나, 수식 입력 중 시트를 오가다 `C2`가 `아이템!C2`로 들어갔어요 | 수식에서 `C2` 앞에 시트 이름이 붙어 있지 않은지 봐요 |
| 행 전체가 아니라 F열만 빨개져요 | 조건부 서식을 F열에만 걸었거나 `$F2` 대신 `F2`를 썼어요 | A2:F13을 선택하고 `=$F2<>""`로 다시 걸어요 |
| 원본을 바꿨는데 피벗이 그대로예요 | 피벗은 자동으로 다시 계산하지 않아요 | **데이터 > 모두 새로 고침** |
| 피벗 값이 `개수 : 수량`으로 나와요 | 수량 열에 빈 칸이나 글자가 섞여 있어요 | 값 필드 설정에서 **합계**로 바꾸고 원본을 확인해요 |
| 피벗 필드 창이 사라졌어요 | 피벗 밖을 클릭했어요 | 피벗 안을 다시 클릭해요. 그래도 없으면 **피벗 테이블 분석 > 필드 목록** |
| 로그 축 옵션이 회색이에요 | 값에 0 이하가 있어요 | 0이나 음수가 없는 범위로 차트를 만들어요 |
| 피벗 칸을 수식으로 참조하면 `GETPIVOTDATA`가 생겨요 | 피벗 칸 참조의 기본 동작이에요 | 그대로 써도 되고, 셀 주소를 직접 입력하면 일반 참조가 돼요 |
